# about the theme

DwellForm is a visual Shopify theme designed for furniture, home, décor, and lifestyle stores. It combines large editorial media with product merchandising tools so you can build landing pages, collection experiences, and product-focused stories directly in the Shopify Theme Editor.

## What you can build

* Large hero experiences including Cinematic Hero, Slideshow, Split Slideshow, Flapped Hero, and interactive text layouts.
* Product merchandising with Featured Collection, Featured Product, Product Hotspots, recommendations, and recently viewed products.
* Visual storytelling with Lookbooks, Image Hotspots, Interactive Hotspots, Visual Story, Panorama View, and Before/After Image Slider.
* Promotional layouts with Promo Grid, Highlight Blocks, Marquee Banner, counters, testimonials, timelines, and video.
* Store-wide cart, predictive search, speech search, product badges, inventory messaging, swatches, wishlist, and Quick Buy controls.
* Pop-up and age-verification overlays.

Most changes can be made without editing theme code.
