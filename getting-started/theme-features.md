# theme features

DwellForm includes a broad set of storefront features that can be configured from the Theme Editor.

## Key features

* Flexible page-building sections and layouts
* Page transition, viewport animation, smooth scrolling, and scroll effects
* Multiple container widths for wide and compact layouts
* Cinematic, slideshow, split, flapped, and interactive-text hero sections
* Featured collections, featured products, product recommendations, and recently viewed products
* Quick Buy, wishlist, product swatches, product badges, and inventory notices
* Image hotspots, product hotspots, interactive hotspots, and lookbooks
* Promo grids, highlight blocks, parallax blocks, counters, timelines, testimonials, and spatial reviews
* Cart drawer with free-shipping goal and optional recommendations
* Predictive search with optional SKU/tag search and speech search
* Pop-up and age-verifier overlays
* Global color schemes, typography, shapes, and card-media controls
* Section dividers on supported sections for decorative transitions between content areas
