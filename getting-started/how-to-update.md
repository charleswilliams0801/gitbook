# how to update

Use a new theme copy when updating DwellForm so your current published store remains available while you review the new version.

## Recommended update process

{% stepper %}
{% step %}
## Open Themes

In Shopify admin, open **Online Store → Themes**.
{% endstep %}

{% step %}
## Create a backup

Duplicate your currently published DwellForm theme as a backup.
{% endstep %}

{% step %}
## Add the updated theme

Add the updated DwellForm theme package to your theme library.
{% endstep %}

{% step %}
## Review the new copy

Open **Customize** on the new copy and review your header, footer, templates, sections, theme settings, and storefront content.
{% endstep %}

{% step %}
## Preview key pages

Preview important pages on desktop and mobile, especially the home page, collection pages, product pages, search, and cart.
{% endstep %}

{% step %}
## Publish when ready

Publish the updated copy only after you are satisfied with the preview.
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
Theme settings and customizations should always be reviewed after installing a new theme package. Keep your previous published version until the new version has been checked.
{% endhint %}
