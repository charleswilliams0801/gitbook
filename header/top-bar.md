# top bar

The Top Bar is the slim utility area above the main header. Use it for announcements, a small menu, social links, language selection, and currency selection.

## Where to find it

Open **Customize → Header group → Top Bar**.

## Section settings

### General

| Setting         | What it controls                                                       |
| --------------- | ---------------------------------------------------------------------- |
| Container width | Chooses container width. Options include: Full, Wide, Default, Narrow. |
| Color scheme    | Chooses the color scheme used for color scheme.                        |

### Section padding

| Setting        | What it controls        |
| -------------- | ----------------------- |
| Padding top    | Adjusts padding top.    |
| Padding bottom | Adjusts padding bottom. |

## Blocks

### Menu

#### General

| Setting        | What it controls                                              |
| -------------- | ------------------------------------------------------------- |
| Top Menu       | Chooses the Shopify menu used for top menu.                   |
| Block Position | Chooses block position. Options include: Left, Center, Right. |

### Announcement

#### General

| Setting           | What it controls                                              |
| ----------------- | ------------------------------------------------------------- |
