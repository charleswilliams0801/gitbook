# main header

The Main Header controls your logo, primary navigation, search, quick links, call-to-action button, sticky behavior, transparent homepage style, and mega menus.

## Where to find it

Open **Customize → Header group → Main header**.

## Recommended setup order

{% stepper %}
{% step %}
## Choose the header layout and container width
{% endstep %}

{% step %}
## Upload the main logo and optional mobile logo
{% endstep %}

{% step %}
## Select the main Shopify navigation menu
{% endstep %}

{% step %}
## Enable search and quick links if required
{% endstep %}

{% step %}
## Add a Column Mega Menu or Tabs Mega Menu block

Only add these blocks for navigation items that need expanded content.
{% endstep %}

{% step %}
## Preview desktop and mobile layouts before publishing
{% endstep %}
{% endstepper %}

{% hint style="info" %}
The transparent header option is intended for the home page. Sticky header behavior can be enabled independently.
{% endhint %}

## Section settings

### General

| Setting                               | What it controls                                |
| ------------------------------------- | ----------------------------------------------- |
| Enable transparent header on homepage | Turns transparent header on homepage on or off. |
| Enable sticky header                  | Turns sticky header on or off.                  |

### Appearance

| Setting                 | What it controls                                           |
| ----------------------- | ---------------------------------------------------------- |
| Color scheme            | Chooses the color scheme used for color scheme.            |
| Wrap menu items         | Turns wrap menu items on or off.                           |
| Menu items color scheme | Chooses the color scheme used for menu items color scheme. |
| Show bottom border      | Shows or hides bottom border.                              |

### Layout

| Setting                   | What it controls                                                                                               |
| ------------------------- | -------------------------------------------------------------------------------------------------------------- |
| Container width           | Chooses container width. Options include: Full, Wide, Default, Small, Narrow.                                  |
| Header layout             | Chooses header layout. Options include: Logo left, menu center, Logo center, menu left, Logo left, under menu. |
| Mobile menu icon position | Chooses mobile menu icon position. Options include: Left, Right.                                               |
| Icon size (px)            | Adjusts icon size (px).                                                                                        |
