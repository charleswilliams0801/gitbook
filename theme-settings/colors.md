# colors

Controls global color schemes plus badge, cart-bubble, rating-star, and focus colors.

## Where to find it

Open **Customize → Theme settings → Colors**.

## Settings

### General

| Setting       | What it controls        |
| ------------- | ----------------------- |
| Color Schemes | Controls color schemes. |

### Default badge

| Setting          | What it controls       |
| ---------------- | ---------------------- |
