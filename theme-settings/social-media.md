# social media

Controls share buttons and the social profile links used by social-icon blocks.

## Where to find it

Open **Customize → Theme settings → Social media**.

## Settings

### Sharing options

| Setting   | What it controls           |
| --------- | -------------------------- |
| Facebook  | Turns facebook on or off.  |
| Twitter   | Turns twitter on or off.   |
| Pinterest | Turns pinterest on or off. |

### Social accounts

| Setting     | What it controls                  |
| ----------- | --------------------------------- |
| Facebook    | Sets the content for facebook.    |
| Instagram   | Sets the content for instagram.   |
| YouTube     | Sets the content for youtube.     |
| TikTok      | Sets the content for tiktok.      |
| X / Twitter | Sets the content for x / twitter. |
| Snapchat    | Sets the content for snapchat.    |
| Pinterest   | Sets the content for pinterest.   |
| Tumblr      | Sets the content for tumblr.      |
| Vimeo       | Sets the content for vimeo.       |
