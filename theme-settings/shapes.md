# shapes

Controls corner styles and sizing for buttons, form fields, cards, images, badges, and modal windows.

## Where to find it

Open **Customize → Theme settings → Shapes**.

## Settings

### Buttons

| Setting       | What it controls                                                            |
| ------------- | --------------------------------------------------------------------------- |
| Button shape  | Chooses button shape. Options include: Square, Slightly round, Round, Pill. |
| Button height | Adjusts button height.                                                      |

### Form fields

| Setting  | What it controls                                                        |
| -------- | ----------------------------------------------------------------------- |
| Inputs   | Chooses inputs. Options include: Square, Slightly round, Round, Pill.   |
| Textarea | Chooses textarea. Options include: Square, Slightly round, Round, Pill. |

### Blocks

| Setting     | What it controls                                                     |
| ----------- | -------------------------------------------------------------------- |
| Block shape | Chooses block shape. Options include: Square, Slightly round, Round. |
| Card shape  | Chooses card shape. Options include: Square, Slightly round, Round.  |

### Images

| Setting     | What it controls                                                     |
| ----------- | -------------------------------------------------------------------- |
| Image shape | Chooses image shape. Options include: Square, Slightly round, Round. |

### Badges

| Setting     | What it controls                                                           |
| ----------- | -------------------------------------------------------------------------- |
| Badge shape | Chooses badge shape. Options include: Square, Slightly round, Round, Pill. |

### Modal

| Setting            | What it controls                                                            |
| ------------------ | --------------------------------------------------------------------------- |
| Modal window shape | Chooses modal window shape. Options include: Square, Slightly round, Round. |
