# cart

Controls cart type, cart icon, after-add behavior, free-shipping goal, and empty-cart recommendations.

## Where to find it

Open **Customize → Theme settings → Cart**.

## Settings

### General

| Setting              | What it controls                                                                                                    |
| -------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Cart type            | Chooses cart type. Options include: Drawer, Page.                                                                   |
| Cart icon            | Chooses cart icon. Options include: Cart, Bag, Basket.                                                              |
| After adding to cart | Chooses after adding to cart. Options include: Show cart drawer, Go to cart page (with quantity check), Do nothing. |

### Free shipping goal

| Setting                      | What it controls                                   |
| ---------------------------- | -------------------------------------------------- |
| Free shipping minimum amount | Sets the content for free shipping minimum amount. |

### Cart empty recommendations

| Setting         | What it controls                                  |
| --------------- | ------------------------------------------------- |
| Messages        | Sets the content for messages.                    |
| Collection list | Chooses the collections used for collection list. |
