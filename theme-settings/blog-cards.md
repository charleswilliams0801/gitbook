# blog cards

Controls blog-card style, metadata, excerpts, and read-more links.

## Where to find it

Open **Customize → Theme settings → Blog cards**.

## Settings

### General

| Setting             | What it controls                                                                                         |
| ------------------- | -------------------------------------------------------------------------------------------------------- |
| Blog card style     | Chooses blog card style. Options include: Default, Boxed.                                                |
| Show tags           | Shows or hides tags.                                                                                     |
| Show excerpt        | Shows or hides excerpt.                                                                                  |
| Show author         | Shows or hides author.                                                                                   |
| Show published date | Shows or hides published date.                                                                           |
| Show read more link | Shows or hides read more link.                                                                           |
| Read more style     | Chooses read more style. Options include: Primary button, Secondary button, Icon only button, Text link. |
| Show read more icon | Shows or hides read more icon.                                                                           |
