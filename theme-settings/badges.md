# badges

Control Sale, Sold out, New, Preorder, and custom product badges.

## Where to find it

Open **Customize → Theme settings → Badges**.

## Settings

### General

| Setting                     | What it controls                                                                              |
| --------------------------- | --------------------------------------------------------------------------------------------- |
| Visibility on product cards | Chooses visibility on product cards. Options include: None, Top left, Top right, Bottom left. |
| Badge style                 | Chooses badge style. Options include: Default, Round, Pill.                                   |

### Sale badge

| Setting           | What it controls                                                                                      |
| ----------------- | ----------------------------------------------------------------------------------------------------- |
| Show "Sale" badge | Shows or hides "sale" badge.                                                                          |
| Icon              | Chooses icon. Options include: None, Award, Box, Briefcase, Calendar, Chat bubble, Check mark, Clock. |
| Sale badge type   | Chooses sale badge type. Options include: Simple text, Percent off, Money off.                        |

### Sold out badge

| Setting               | What it controls                                                                                      |
| --------------------- | ----------------------------------------------------------------------------------------------------- |
| Show "Sold out" badge | Shows or hides "sold out" badge.                                                                      |
| Icon                  | Chooses icon. Options include: None, Award, Box, Briefcase, Calendar, Chat bubble, Check mark, Clock. |

### New badge

| Setting                                                     | What it controls                                                                                      |
| ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Show "New" badge                                            | Shows or hides "new" badge.                                                                           |
| Icon                                                        | Chooses icon. Options include: None, Award, Box, Briefcase, Calendar, Chat bubble, Check mark, Clock. |
| Show "New" badge for products in the following collections  | Shows or hides "new" badge for products in the following collections.                                 |
| "New" collections                                           | Chooses the collections used for "new" collections.                                                   |
| Show "New" badge for products with the following tag        | Shows or hides "new" badge for products with the following tag.                                       |
| "New" tag                                                   | Sets the content for "new" tag.                                                                       |
| Show "New" badge for products created within this many days | Shows or hides "new" badge for products created within this many days.                                |
| Days ago created                                            | Adjusts days ago created.                                                                             |

### Preorder badge

| Setting | What it controls                                                                                      |
| ------- | ----------------------------------------------------------------------------------------------------- |
| Icon    | Chooses icon. Options include: None, Award, Box, Briefcase, Calendar, Chat bubble, Check mark, Clock. |

### Custom badge

| Setting       | What it controls                                                                                      |
| ------------- | ----------------------------------------------------------------------------------------------------- |
| Icon          | Chooses icon. Options include: None, Award, Box, Briefcase, Calendar, Chat bubble, Check mark, Clock. |
| Custom badges | Sets the content for custom badges.                                                                   |
