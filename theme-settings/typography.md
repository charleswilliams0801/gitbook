# typography

Controls fonts, sizes, weights, spacing, and text transformations across the storefront.

## Where to find it

Open **Customize → Theme settings → Typography**.

## Settings

### Body

| Setting            | What it controls                                                                         |
| ------------------ | ---------------------------------------------------------------------------------------- |
| Font family        | Chooses the font used for font family.                                                   |
| Bolder font weight | Chooses bolder font weight. Options include: Medium, Semi bold, Bold, Extra bold, Black. |
| Line height        | Adjusts line height.                                                                     |

### Heading

| Setting        | What it controls                       |
| -------------- | -------------------------------------- |
| Font family    | Chooses the font used for font family. |
| Letter spacing | Adjusts letter spacing.                |
| Line height    | Adjusts line height.                   |
| Uppercase      | Turns uppercase on or off.             |

### Subheading

| Setting     | What it controls                                                                                 |
