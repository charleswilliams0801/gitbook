# product cards

Controls the appearance and shopping features used by product cards across collections and product grids.

## Where to find it

Open **Customize → Theme settings → Product cards**.

## Settings

### General

| Setting    | What it controls                                     |
| ---------- | ---------------------------------------------------- |
| Card style | Chooses card style. Options include: Default, Boxed. |

### Product information

| Setting                               | What it controls                                       |
| ------------------------------------- | ------------------------------------------------------ |
| Show swatches under images            | Shows or hides swatches under images.                  |
| Show vendor                           | Shows or hides vendor.                                 |
| Show SKU                              | Shows or hides SKU.                                    |
| Show rating                           | Shows or hides rating.                                 |
| Show price                            | Shows or hides price.                                  |
| Show weight                           | Shows or hides weight.                                 |
| Show product inventory                | Shows or hides product inventory.                      |
| Align price to the bottom of the card | Turns align price to the bottom of the card on or off. |

### Quick Buy

| Setting                                 | What it controls                                                                                                               |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Enable Quick Buy                        | Turns quick buy on or off.                                                                                                     |
| Add to Cart appearance on mobile        | Chooses add to cart appearance on mobile. Options include: Text button at the bottom, Icon over image.                         |
| Add to Cart appearance on large screens | Chooses add to cart appearance on large screens. Options include: Icon over image, Button on hover, Text button at the bottom. |

### Wishlist

| Setting         | What it controls          |
| --------------- | ------------------------- |
| Enable wishlist | Turns wishlist on or off. |

### Color swatches

| Setting                  | What it controls                                                                                |
| ------------------------ | ----------------------------------------------------------------------------------------------- |
| Swatches type            | Chooses swatches type. Options include: None, Shopify, Text, Swatch color list, Variant images. |
| Maximum swatches to show | Adjusts maximum swatches to show.                                                               |
| Icon shape               | Chooses icon shape. Options include: Natural, Portrait, Square, Circle.                         |
| Icon size                | Adjusts icon size.                                                                              |

### Badges

| Setting             | What it controls                                                          |
| ------------------- | ------------------------------------------------------------------------- |
| Show product badges | Shows or hides product badges.                                            |
| Sale badge type     | Chooses sale badge type. Options include: Text, Percentage, Fixed amount. |

### Mobile layout

| Setting                         | What it controls                                       |
| ------------------------------- | ------------------------------------------------------ |
| Hide quick add button on mobile | Controls whether quick add button on mobile is hidden. |
