# search behavior

Controls predictive search, result details, SKU/tag matching, popular keywords, and speech search.

## Where to find it

Open **Customize → Theme settings → Search behavior**.

## Settings

### General

| Setting                  | What it controls                   |
| ------------------------ | ---------------------------------- |
| Enable predictive search | Turns predictive search on or off. |

### Predictive search

| Setting                                         | What it controls                                         |
| ----------------------------------------------- | -------------------------------------------------------- |
| Maximum number of items to show per result type | Adjusts maximum number of items to show per result type. |
| Show product vendor                             | Shows or hides product vendor.                           |
| Show product price                              | Shows or hides product price.                            |
| Search SKUs                                     | Turns search skus on or off.                             |
| Search tags                                     | Turns search tags on or off.                             |
| Most searched keywords                          | Sets the content for most searched keywords.             |

### Speech search

| Setting              | What it controls               |
| -------------------- | ------------------------------ |
| Enable speech search | Turns speech search on or off. |
| Speech pulse color   | Sets speech pulse color.       |
