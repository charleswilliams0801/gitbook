# main footer

The Main Footer is the store-wide area used for navigation, newsletter signup, brand information, social links, selectors, payment icons, and copyright content.

## Where to find it

Open **Customize → Footer group → Main footer**.

## Recommended setup order

{% stepper %}
{% step %}
## Choose the footer appearance

Choose the footer color scheme and container width.
{% endstep %}

{% step %}
## Add footer blocks

Add Footer menu, Image and text, or Newsletter signup blocks.
{% endstep %}

{% step %}
## Enable selectors

Enable language or currency selectors when your store uses them.
{% endstep %}

{% step %}
## Enable payment icons

Enable payment icons if you want supported payment methods shown.
{% endstep %}

{% step %}
## Choose the secondary menu

Choose the secondary menu for copyright-area links such as policies.
{% endstep %}
{% endstepper %}

## Section settings

### Appearance

| Setting                | What it controls                                                       |
| ---------------------- | ---------------------------------------------------------------------- |
| Container width        | Chooses container width. Options include: Full, Wide, Default, Narrow. |
| Color scheme           | Chooses the color scheme used for color scheme.                        |
| Copyright color scheme | Chooses the color scheme used for copyright color scheme.              |
| Show payment icons     | Shows or hides payment icons.                                          |

### Background media

| Setting               | What it controls                                                |
| --------------------- | --------------------------------------------------------------- |
| Background media      | Chooses background media. Options include: None, Image, Video.  |
| Video                 | Selects the video used for video.                               |
| Image                 | Selects the image used for image.                               |
| Background size       | Chooses background size. Options include: Cover, Contain.       |
| Background attachment | Chooses background attachment. Options include: Fixed, Default. |
| Background opacity    | Adjusts background opacity.                                     |

### Currency selector

| Setting                  | What it controls                   |
| ------------------------ | ---------------------------------- |
| Enable currency selector | Turns currency selector on or off. |

### Language selector

| Setting                  | What it controls                   |
| ------------------------ | ---------------------------------- |
| Enable language selector | Turns language selector on or off. |

### Copyright

| Setting                   | What it controls                     |
| ------------------------- | ------------------------------------ |
| Show 'Powered by Shopify' | Shows or hides 'powered by shopify'. |

### Secondary menu

| Setting        | What it controls                                  |
| -------------- | ------------------------------------------------- |
| Secondary menu | Chooses the Shopify menu used for secondary menu. |

### Section padding

| Setting        | What it controls        |
| -------------- | ----------------------- |
| Padding top    | Adjusts padding top.    |
| Padding bottom | Adjusts padding bottom. |

## Blocks

### Footer menu

#### General

| Setting      | What it controls                                               |
| ------------ | -------------------------------------------------------------- |
| Block width  | Adjusts block width.                                           |
| Heading      | Sets the content for heading.                                  |
| Heading size | Chooses heading size. Options include: H6, H5, H4, H3, H2, H1. |
| Menu         | Chooses the Shopify menu used for menu.                        |
