# sequence frames

Creates a frame-by-frame visual sequence for an animated storytelling effect.

## How to add this section

{% stepper %}
{% step %}
## Open the theme customizer

Open **Shopify admin → Online Store → Themes → Customize**.
{% endstep %}

{% step %}
## Open a template

Open the template where you want the content to appear.
{% endstep %}

{% step %}
## Add the section

Select **Add section** and choose **Sequence Frames**.
{% endstep %}

{% step %}
## Configure the section

Configure the section settings and add or reorder blocks when available.
{% endstep %}

{% step %}
## Preview and save

Preview desktop and mobile layouts, then save your changes.
{% endstep %}
{% endstepper %}

## Section settings

### Appearance

| Setting                  | What it controls                                |
| ------------------------ | ----------------------------------------------- |
| Color scheme             | Chooses the color scheme used for color scheme. |
| Sequence scroll distance | Adjusts sequence scroll distance.               |
| Desktop frame smoothing  | Adjusts desktop frame smoothing.                |
| Sticky header clearance  | Adjusts sticky header clearance.                |

### Section header

| Setting             | What it controls                          |
| ------------------- | ----------------------------------------- |
| Eyebrow             | Sets the content for eyebrow.             |
| Sequence heading    | Sets the content for sequence heading.    |
| Sequence subheading | Sets the content for sequence subheading. |

### Frames

| Setting                   | What it controls                                          |
| ------------------------- | --------------------------------------------------------- |
| Sequence poster           | Selects the image used for sequence poster.               |
| Image description         | Sets the content for image description.                   |
| Custom frame URL template | Sets the content for custom frame url template.           |
| Frame count               | Adjusts frame count.                                      |
| First frame number        | Adjusts first frame number.                               |
| Frame number digits       | Adjusts frame number digits.                              |
| Frame image fit           | Chooses frame image fit. Options include: Cover, Contain. |

## Available blocks

### Specification

#### General
