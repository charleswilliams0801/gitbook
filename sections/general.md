# general

Controls global movement, scrolling, and page-width behavior.

## Where to find it

Open **Customize → Theme settings → General**.

## Settings

### General

| Setting                      | What it controls                       |
| ---------------------------- | -------------------------------------- |
| Enable back to top button    | Turns back to top button on or off.    |
| Enable page transition       | Turns page transition on or off.       |
| Enable animation in viewport | Turns animation in viewport on or off. |
| Enable smooth scrolling      | Turns smooth scrolling on or off.      |
| Enable scroll effect         | Turns scroll effect on or off.         |

### Layouts

| Setting                   | What it controls                   |
| ------------------------- | ---------------------------------- |
| Container width (default) | Adjusts container width (default). |
| Container width (small)   | Adjusts container width (small).   |
| Container width (narrow)  | Adjusts container width (narrow).  |
