# image hotspots

Places clickable hotspots over an image to explain features or direct customers to products and pages.

## How to add this section

{% stepper %}
{% step %}
## Open the theme customizer

Open **Shopify admin → Online Store → Themes → Customize**.
{% endstep %}

{% step %}
## Open a template

Open the template where you want the content to appear.
{% endstep %}

{% step %}
## Add the section

Select **Add section** and choose **Image hotspots**.
{% endstep %}

{% step %}
## Configure the section

Configure the section settings and add or reorder blocks when available.
{% endstep %}

{% step %}
## Preview and save

Preview desktop and mobile layouts, then save your changes.
{% endstep %}
{% endstepper %}

## Section settings

### Appearance

| Setting                               | What it controls                                                                                                |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Color scheme                          | Chooses the color scheme used for color scheme.                                                                 |
| Scroll into view animation            | Chooses scroll into view animation. Options include: Fade in, Slide left, Slide right, Slide top, Slide bottom. |
| Container width                       | Chooses container width. Options include: Full, Wide, Default, Small, Narrow.                                   |
| Section height                        | Chooses section height. Options include: Default, Fixed height, Full screen height.                             |
| Minimum fixed height on large screens | Adjusts minimum fixed height on large screens.                                                                  |
| Minimum fixed height on mobile        | Adjusts minimum fixed height on mobile.                                                                         |

### Background media

| Setting               | What it controls                                                |
| --------------------- | --------------------------------------------------------------- |
| Background media      | Chooses background media. Options include: None, Image, Video.  |
| Video                 | Selects the video used for video.                               |
| Image                 | Selects the image used for image.                               |
| Background size       | Chooses background size. Options include: Cover, Contain.       |
| Background attachment | Chooses background attachment. Options include: Fixed, Default. |
| Background opacity    | Adjusts background opacity.                                     |

### Section header

| Setting           | What it controls                                                                                          |
| ----------------- | --------------------------------------------------------------------------------------------------------- |
| Heading           | Sets the content for heading.                                                                             |
| Heading size      | Chooses heading size. Options include: Extra extra small, Extra small, Small, Medium, Large, Extra large. |
| Subheading        | Sets the content for subheading.                                                                          |
| Subheading font   | Chooses subheading font. Options include: Body, Heading.                                                  |
| Heading alignment | Chooses heading alignment. Options include: Left, Center, Right.                                          |

### Image

| Setting       | What it controls                          |
| ------------- | ----------------------------------------- |
| Desktop image | Selects the image used for desktop image. |
| Mobile image  | Selects the image used for mobile image.  |

### Colors

| Setting          | What it controls       |
| ---------------- | ---------------------- |
| Point background | Sets point background. |
| Point color      | Sets point color.      |
| Background       | Sets background.       |
| Text color       | Sets text color.       |

### Section padding

| Setting        | What it controls        |
| -------------- | ----------------------- |
| Padding top    | Adjusts padding top.    |
| Padding bottom | Adjusts padding bottom. |

## Available blocks

### Hotspot

#### Point position (desktop)

| Setting | What it controls |
| ------- | ---------------- |
| Top     | Adjusts top.     |
| Left    | Adjusts left.    |

#### Point position (mobile)

| Setting | What it controls |
| ------- | ---------------- |
| Top     | Adjusts top.     |
| Left    | Adjusts left.    |

#### Tooltip

| Setting                    | What it controls                                                               |
| -------------------------- | ------------------------------------------------------------------------------ |
| Tooltip text               | Sets the content for tooltip text.                                             |
| Tooltip position           | Chooses tooltip position. Options include: Top, Bottom, Left, Right.           |
| Tooltip position on mobile | Chooses tooltip position on mobile. Options include: Top, Bottom, Left, Right. |
| Tooltip width              | Adjusts tooltip width.                                                         |
| Tooltip width on mobile    | Adjusts tooltip width on mobile.                                               |

## Tips

* Place hotspots where they do not cover important visual details.
* Use concise hotspot labels so customers can understand them quickly.
