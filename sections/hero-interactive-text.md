# hero interactive text

Creates a hero area centered around animated or interactive text.

## How to add this section

{% stepper %}
{% step %}
## Open the theme customizer

Open **Shopify admin → Online Store → Themes → Customize**.
{% endstep %}

{% step %}
## Open a template

Open the template where you want the content to appear.
{% endstep %}

{% step %}
## Add the section

Select **Add section** and choose **Hero interactive text**.
{% endstep %}

{% step %}
## Configure the section

Configure the section settings and add or reorder blocks when available.
{% endstep %}

{% step %}
## Preview and save

Preview desktop and mobile layouts, then save your changes.
{% endstep %}
{% endstepper %}

## Section settings

### Appearance

| Setting                               | What it controls                                                                       |
| ------------------------------------- | -------------------------------------------------------------------------------------- |
| Color scheme                          | Chooses the color scheme used for color scheme.                                        |
| Container width                       | Chooses container width. Options include: Full, Wide, Default, Small, Narrow.          |
| Section height                        | Chooses section height. Options include: Default, Fixed height, Full screen height.    |
| Minimum fixed height on large screens | Adjusts minimum fixed height on large screens.                                         |
| Minimum fixed height on mobile        | Adjusts minimum fixed height on mobile.                                                |
| Text effect                           | Chooses text effect. Options include: Writing text, Highlighting text, Revealing text. |

### Background media

| Setting               | What it controls                                                |
| --------------------- | --------------------------------------------------------------- |
| Background media      | Chooses background media. Options include: None, Image, Video.  |
| Video                 | Selects the video used for video.                               |
| Image                 | Selects the image used for image.                               |
| Background size       | Chooses background size. Options include: Cover, Contain.       |
| Background attachment | Chooses background attachment. Options include: Fixed, Default. |
| Background opacity    | Adjusts background opacity.                                     |

### Content

| Setting   | What it controls                                                                                       |
| --------- | ------------------------------------------------------------------------------------------------------ |
| Long text | Sets the content for long text.                                                                        |
| Text size | Chooses text size. Options include: Extra extra small, Extra small, Small, Medium, Large, Extra large. |
| Font      | Chooses font. Options include: Body, Heading.                                                          |

### Section padding

| Setting        | What it controls        |
| -------------- | ----------------------- |
| Padding top    | Adjusts padding top.    |
| Padding bottom | Adjusts padding bottom. |
