# before after image slider

Lets visitors compare two images with an interactive before-and-after slider.

## How to add this section

{% stepper %}
{% step %}
## Open the theme customizer

Open **Shopify admin → Online Store → Themes → Customize**.
{% endstep %}

{% step %}
## Choose a template

Open the template where you want the content to appear.
{% endstep %}

{% step %}
## Add the section

Select **Add section** and choose **Before / After Image Slider**.
{% endstep %}

{% step %}
## Configure the section

Configure the section settings and add or reorder blocks when available.
{% endstep %}

{% step %}
## Preview and save

Preview desktop and mobile layouts, then save your changes.
{% endstep %}
{% endstepper %}

## Section settings

### General

| Setting                  | What it controls                           |
| ------------------------ | ------------------------------------------ |
| Eyebrow                  | Sets the content for eyebrow.              |
| Heading                  | Sets the content for heading.              |
| Intro                    | Sets the content for intro.                |
| Before image             | Selects the image used for before image.   |
| Before label             | Sets the content for before label.         |
| After image              | Selects the image used for after image.    |
| After label              | Sets the content for after label.          |
| Initial divider position | Adjusts initial divider position.          |
