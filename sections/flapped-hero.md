# flapped hero

Creates an editorial hero with flap-style content for a strong first impression.

## How to add this section

{% stepper %}
{% step %}
## Open the theme customizer

Open **Shopify admin → Online Store → Themes → Customize**.
{% endstep %}

{% step %}
## Choose a template

Open the template where you want the content to appear.
{% endstep %}

{% step %}
## Add the section

Select **Add section** and choose **Flapped Hero**.
{% endstep %}

{% step %}
## Configure content

Configure the section settings and add or reorder blocks when available.
{% endstep %}

{% step %}
## Preview and save

Preview desktop and mobile layouts, then save your changes.
{% endstep %}
{% endstepper %}

## Section settings

### Appearance

| Setting            | What it controls            |
| ------------------ | --------------------------- |
| Overlay background | Sets overlay background.    |
| Overlay opacity    | Adjusts overlay opacity.    |
| Gap between blocks | Adjusts gap between blocks. |

### Layout

| Setting                   | What it controls                                                              |
| ------------------------- | ----------------------------------------------------------------------------- |
| Container width           | Chooses container width. Options include: Full, Wide, Default, Small, Narrow. |
| Section height on desktop | Adjusts section height on desktop.                                            |
| Section height on mobile  | Adjusts section height on mobile.                                             |
| Expansions                | Adjusts expansions.                                                           |

### Content

| Setting           | What it controls                                                 |
| ----------------- | ---------------------------------------------------------------- |
| Color scheme      | Chooses the color scheme used for color scheme.                  |
| Content alignment | Chooses content alignment. Options include: Left, Center, Right. |

## Available blocks

### Accordion Panel

#### Appearance

| Setting                           | What it controls                                                 |
| --------------------------------- | ---------------------------------------------------------------- |
| Inherit color scheme from section | Turns inherit color scheme from section on or off.               |
| Color scheme                      | Chooses the color scheme used for color scheme.                  |
| Overlay background                | Sets overlay background.                                         |
| Overlay opacity                   | Adjusts overlay opacity.                                         |
| Content position                  | Chooses content position. Options include: Top, Middle, Bottom.  |
| Content alignment                 | Chooses content alignment. Options include: Left, Center, Right. |

#### Content

| Setting          | What it controls                                                                                            |
| ---------------- | ----------------------------------------------------------------------------------------------------------- |
| Background Image | Selects the image used for background image.                                                                |
| Subheading       | Sets the content for subheading.                                                                            |
| Subheading font  | Chooses subheading font. Options include: Body, Heading.                                                    |
| Heading          | Sets the content for heading.                                                                               |
| Heading size     | Chooses heading size. Options include: Extra extra small, Extra small, Medium, Large, Extra large.          |
| Description      | Sets the content for description.                                                                           |
| Button Label     | Sets the content for button label.                                                                          |
| Icon             | Chooses icon. Options include: None, Alert, Arrow in circle, Arrow left, Arrow right, Arrow up, Award, Bag. |
| Icon position    | Chooses icon position. Options include: Left, Right.                                                        |
| Button URL       | Sets the destination link for button url.                                                                   |
| Button style     | Chooses button style. Options include: Primary, Secondary, Plain, Link, Icon.                               |
