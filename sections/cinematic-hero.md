# cinematic hero

Creates an immersive scene-based hero for large visual storytelling.

## How to add this section

{% stepper %}
{% step %}
## Open the theme editor

Open **Shopify admin → Online Store → Themes → Customize**.
{% endstep %}

{% step %}
## Choose a template

Open the template where you want the content to appear.
{% endstep %}

{% step %}
## Add the section

Select **Add section** and choose **Cinematic hero**.
{% endstep %}

{% step %}
## Configure the section

Configure the section settings and add or reorder blocks when available.
{% endstep %}

{% step %}
## Preview and save

Preview desktop and mobile layouts, then save your changes.
{% endstep %}
{% endstepper %}

## Section settings

### General

| Setting                    | What it controls                                |
| -------------------------- | ----------------------------------------------- |
| Color scheme               | Chooses the color scheme used for color scheme. |
| Accessible section name    | Sets the content for accessible section name.   |
| Use H1 for the first scene | Turns use h1 for the first scene on or off.     |

## Available blocks

### Scene

#### Appearance

| Setting              | What it controls                                                                                   |
| -------------------- | -------------------------------------------------------------------------------------------------- |
| Inherit color scheme | Turns inherit color scheme on or off.                                                              |
| Color scheme         | Chooses the color scheme used for color scheme.                                                    |
| Content position     | Chooses content position. Options include: Middle center, Middle left, Bottom center, Bottom left. |
| Content alignment    | Chooses content alignment. Options include: Left, Center, Right.                                   |
| Content width        | Adjusts content width.                                                                             |

#### Media

| Setting                        | What it controls                                           |
| ------------------------------ | ---------------------------------------------------------- |
| Desktop image / video fallback | Selects the image used for desktop image / video fallback. |
| Mobile image                   | Selects the image used for mobile image.                   |
| Optional background video      | Selects the video used for optional background video.      |
| Enable gradient overlay        | Turns gradient overlay on or off.                          |
| Overlay opacity                | Adjusts overlay opacity.                                   |

#### Content

| Setting         | What it controls                                                                                            |
| --------------- | ----------------------------------------------------------------------------------------------------------- |
| Heading         | Sets the content for heading.                                                                               |
| Heading size    | Chooses heading size. Options include: Extra extra small, Extra small, Small, Medium, Large, Extra large.   |
| Subheading      | Sets the content for subheading.                                                                            |
| Subheading size | Chooses subheading size. Options include: Body size, Small.                                                 |
| Subheading font | Chooses subheading font. Options include: Heading font, Body font.                                          |
| Description     | Sets the content for description.                                                                           |
| Button label    | Sets the content for button label.                                                                          |
| Icon            | Chooses icon. Options include: None, Alert, Arrow in circle, Arrow left, Arrow right, Arrow up, Award, Bag. |
| Icon position   | Chooses icon position. Options include: Left, Right.                                                        |
| Button style    | Chooses button style. Options include: Primary button, Secondary button, Plain text, Link, Icon.            |
| Button link     | Sets the destination link for button link.                                                                  |
| Open in new tab | Turns open in new tab on or off.                                                                            |

## Tips

* Use high-quality media and keep important text away from busy image areas.
* Preview motion and text on both desktop and mobile.
