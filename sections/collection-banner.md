# collection banner

Creates a collection header with media, collection information, and layout controls.

## How to add this section

{% stepper %}
{% step %}
## Open the theme editor

Open **Shopify admin → Online Store → Themes → Customize**.
{% endstep %}

{% step %}
## Open the template

Open the template where you want the content to appear.
{% endstep %}

{% step %}
## Add the section

Select **Add section** and choose **Collection Banner**.
{% endstep %}

{% step %}
## Configure the section

Configure the section settings and add or reorder blocks when available.
{% endstep %}

{% step %}
## Preview and save

Preview desktop and mobile layouts, then save your changes.
{% endstep %}
{% endstepper %}

## Section settings

### Apperance

| Setting                               | What it controls                                                                                                |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Color scheme                          | Chooses the color scheme used for color scheme.                                                                 |
| Scroll into view animation            | Chooses scroll into view animation. Options include: Fade in, Slide left, Slide right, Slide top, Slide bottom. |
| Container width                       | Chooses container width. Options include: Full, Wide, Default, Small, Narrow.                                   |
| Section height                        | Chooses section height. Options include: Default, Fixed height, Full screen height.                             |
| Minimum fixed height on large screens | Adjusts minimum fixed height on large screens.                                                                  |
| Minimum fixed height on mobile        | Adjusts minimum fixed height on mobile.                                                                         |
| Enable fullpage scroll animation      | Turns fullpage scroll animation on or off.                                                                      |

### Background media

| Setting               | What it controls                                                |
| --------------------- | --------------------------------------------------------------- |
| Background media      | Chooses background media. Options include: None, Image, Video.  |
| Video                 | Selects the video used for video.                               |
| Image                 | Selects the image used for image.                               |
| Background size       | Chooses background size. Options include: Cover, Contain.       |
| Background attachment | Chooses background attachment. Options include: Fixed, Default. |
| Background opacity    | Adjusts background opacity.                                     |

### Content

| Setting                     | What it controls                                                                                             |
| --------------------------- | ------------------------------------------------------------------------------------------------------------ |
| Show collection title       | Shows or hides collection title.                                                                             |
| Title size                  | Chooses title size. Options include: Extra extra small, Extra small, Small, Medium, Large, Extra large.      |
| Show collection description | Shows or hides collection description.                                                                       |
| Content alignment           | Chooses content alignment. Options include: Left, Center, Right.                                             |
| Show collection image       | Shows or hides collection image.                                                                             |
| Custom mage                 | Selects the image used for custom mage.                                                                      |
| Image position              | Chooses image position. Options include: Left, Right.                                                        |
| Image width                 | Adjusts image width.                                                                                         |
| Featured image ratio        | Chooses featured image ratio. Options include: Natural, Landscape (4:3), Landscape (16:9), Square, Portrait. |

### Additional Content

| Setting                   | What it controls                                                                                                      |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Enable subcollection      | Turns subcollection on or off.                                                                                        |
| Title                     | Sets the content for title.                                                                                           |
| Subcollection title size  | Chooses subcollection title size. Options include: Extra extra small, Extra small, Small, Medium, Large, Extra large. |
| Subcollections            | Chooses the collections used for subcollections.                                                                      |
| Layout                    | Chooses layout. Options include: Carousel, Grid.                                                                      |
| Show scrollbar            | Shows or hides scrollbar.                                                                                             |
| Item style                | Chooses item style. Options include: Button, Card.                                                                    |
| Button type               | Chooses button type. Options include: Primary, Secondary.                                                             |
| Subcollection image width | Adjusts subcollection image width.                                                                                    |
| Image ratio               | Chooses image ratio. Options include: Natural, Landscape (4:3), Landscape (16:9), Square, Portrait.                   |

### Section padding

| Setting        | What it controls        |

| Padding top    | Adjusts padding top.    |
