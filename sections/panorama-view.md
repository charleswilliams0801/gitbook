# panorama view

Presents wide visual media in an immersive panorama-style section.

## How to add this section

{% stepper %}
{% step %}
## Open the theme customizer

Open **Shopify admin → Online Store → Themes → Customize**.
{% endstep %}

{% step %}
## Open a template

Open the template where you want the content to appear.
{% endstep %}

{% step %}
## Add the section

Select **Add section** and choose **Panorama View**.
{% endstep %}

{% step %}
## Configure content

Configure the section settings and add or reorder blocks when available.
{% endstep %}

{% step %}
## Preview and save

Preview desktop and mobile layouts, then save your changes.
{% endstep %}
{% endstepper %}

## Section settings

### General

| Setting                 | What it controls                              |
| ----------------------- | --------------------------------------------- |
| Brand                   | Sets the content for brand.                   |
| Accessible section name | Sets the content for accessible section name. |
| Image description       | Sets the content for image description.       |
| Enable drag controls    | Turns drag controls on or off.                |
| Show viewpoint slider   | Shows or hides viewpoint slider.              |
| Desktop scroll distance | Adjusts desktop scroll distance.              |
| Mobile scroll distance  | Adjusts mobile scroll distance.               |
| Sticky header clearance | Adjusts sticky header clearance.              |
| Text color              | Sets text color.                              |
| Shade opacity           | Adjusts shade opacity.                        |

### Panorama images

| Setting                      | What it controls                                                                                                                                |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Panorama image               | Selects the image used for panorama image.                                                                                                      |
| Image type                   | Chooses image type. Options include: Full 360 equirectangular panorama, Partial equirectangular panorama, Wide photo (no spherical distortion). |
| Partial: horizontal coverage | Adjusts partial: horizontal coverage.                                                                                                           |
| Partial: vertical coverage   | Adjusts partial: vertical coverage.                                                                                                             |
| Panorama detail              | Chooses panorama detail. Options include: Automatic (recommended), Standard, High.                                                              |
