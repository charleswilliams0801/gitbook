# color swatches

Defines which product option is treated as a color option and maps swatch names to colors.

## Where to find it

Open **Customize → Theme settings → Color swatches**.

## Settings

### General

| Setting           | What it controls                        |
| ----------------- | --------------------------------------- |
| Color option name | Sets the content for color option name. |
| Swatch color list | Sets the content for swatch color list. |
