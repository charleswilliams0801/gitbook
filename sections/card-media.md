# card media

Controls image ratios, fit, animation, and hover behavior used by product and blog cards.

## Where to find it

Open **Customize → Theme settings → Card media**.

## Settings

### General

| Setting      | What it controls                                   |
| ------------ | -------------------------------------------------- |
| Hover effect | Chooses hover effect. Options include: Grow, Tilt. |

### Product cards

| Setting            | What it controls                                                                                      |
| ------------------ | ----------------------------------------------------------------------------------------------------- |
| Image aspect ratio | Chooses image aspect ratio. Options include: Landscape, Square, Portrait.                             |
| Image fit          | Chooses image fit. Options include: Natural, Cover.                                                   |
| Image animation    | Chooses image animation. Options include: Slideshow, Show second image on hover, Only featured image. |

### Blog cards

| Setting     | What it controls                                                                                                      |
| ----------- | --------------------------------------------------------------------------------------------------------------------- |
| Image ratio | Chooses image ratio. Options include: Height of shortest image, Height of tallest image, Landscape, Square, Portrait. |
| Image fit   | Chooses image fit. Options include: Natural, Cover.                                                                   |
