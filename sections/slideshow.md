# slideshow

Creates a standard multi-slide hero or promotional slideshow.

## How to add this section

{% stepper %}
{% step %}
## Open the theme editor

Open **Shopify admin → Online Store → Themes → Customize**.
{% endstep %}

{% step %}
## Open the template

Open the template where you want the content to appear.
{% endstep %}

{% step %}
## Add the section

Select **Add section** and choose **Slideshow**.
{% endstep %}

{% step %}
## Configure slides

Configure the section settings and add or reorder blocks when available.
{% endstep %}

{% step %}
## Preview and save

Preview desktop and mobile layouts, then save your changes.
{% endstep %}
{% endstepper %}

## Section settings

### Appearance

| Setting         | What it controls                                                              |
| --------------- | ----------------------------------------------------------------------------- |
| Color scheme    | Chooses the color scheme used for color scheme.                               |
| Container width | Chooses container width. Options include: Full, Wide, Default, Small, Narrow. |

### Layout

| Setting                               | What it controls                                                                                            |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Image height                          | Chooses image height. Options include: Height of first image, Fixed height (set below), Full screen height. |
| Minimum fixed height on large screens | Adjusts minimum fixed height on large screens.                                                              |
| Minimum fixed height on mobile        | Adjusts minimum fixed height on mobile.                                                                     |
| Show text below image on mobile       | Shows or hides text below image on mobile.                                                                  |

### Slideshow appearance

| Setting             | What it controls                                                        |
| ------------------- | ----------------------------------------------------------------------- |
| Pagination style    | Chooses pagination style. Options include: Arrows, Dots, Lines.         |
| Pagination color    | Sets pagination color.                                                  |
| Pagination position | Chooses pagination position. Options include: Left, Center, Right.      |
| Slide transition    | Chooses slide transition. Options include: Slide and fade, Slide, Fade. |
| Auto-rotate slides  | Turns auto-rotate slides on or off.                                     |
| Show pause button   | Shows or hides pause button.                                            |
| Change slides every | Adjusts change slides every.                                            |

### Style

| Setting                            | What it controls                                    |
| ---------------------------------- | --------------------------------------------------- |
| Color scheme                       | Chooses the color scheme used for color scheme.     |
| Make section background full width | Turns make section background full width on or off. |

### Accessibility / SEO

| Setting                            | What it controls                                    |
| ---------------------------------- | --------------------------------------------------- |
| Slideshow description              | Sets the content for slideshow description.         |
| Load the section without animation | Turns load the section without animation on or off. |

## Tips

* Keep slide messaging short and readable.
* Use media with similar proportions across slides for a steadier layout.
