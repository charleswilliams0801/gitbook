# search drawer

The Search Drawer provides a slide-out search experience and can include promotional products, collections, or media below the search area.

## Where to find it

Open **Customize → Overlay → Search drawer**. Predictive and speech-search behavior is controlled under **Theme settings → Search behavior**.

## Section settings

### Search header

| Setting      | What it controls                   |
| ------------ | ---------------------------------- |
| Drawer Title | Sets the content for drawer title. |

### Color scheme

| Setting      | What it controls                                |
| ------------ | ----------------------------------------------- |
| Header       | Chooses the color scheme used for header.       |
| Main content | Chooses the color scheme used for main content. |

## Blocks

### Promotion products

| Setting      | What it controls                                               |
| ------------ | -------------------------------------------------------------- |
| Heading      | Sets the content for heading.                                  |
| Heading size | Chooses heading size. Options include: H6, H5, H4, H3, H2, H1. |
| Products     | Chooses the products used for products.                        |
| Layout       | Chooses layout. Options include: Carousel, Grid.               |
| Column gap   | Adjusts column gap.                                            |

### Promoted collections

| Setting      | What it controls                                               |
| ------------ | -------------------------------------------------------------- |
| Heading      | Sets the content for heading.                                  |
| Heading size | Chooses heading size. Options include: H6, H5, H4, H3, H2, H1. |
| Collections  | Chooses the collections used for collections.                  |
