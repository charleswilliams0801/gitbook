# age verifier

The Age Verifier displays a store-entry confirmation before visitors continue. Use it only when your store needs an age acknowledgement.

## Where to find it

Open **Customize → Overlay → Age verifier**.

## Section settings

### Style

| Setting      | What it controls                                |
| ------------ | ----------------------------------------------- |
| Color scheme | Chooses the color scheme used for color scheme. |
| Mode         | Chooses mode. Options include: Light, Dark.     |
