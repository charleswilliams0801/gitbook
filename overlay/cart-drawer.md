# cart drawer

The Cart Drawer lets customers review their cart without leaving the current page. It can include cart items, promotional products or media, order notes, shipping information, checkout controls, and a shipping calculator.

## Where to find it

Open **Customize → Overlay → Cart drawer**. Also check **Theme settings → Cart** to choose the store-wide cart behavior.

## Section settings

### Cart header

| Setting      | What it controls                                               |
| ------------ | -------------------------------------------------------------- |
| Drawer title | Sets the content for drawer title.                             |
| Heading size | Chooses heading size. Options include: H6, H5, H4, H3, H2, H1. |
| Cart message | Sets the content for cart message.                             |

### Color scheme

| Setting      | What it controls                                |
| ------------ | ----------------------------------------------- |
| Main content | Chooses the color scheme used for main content. |
| Message bar  | Chooses the color scheme used for message bar.  |

### Cart summary

| Setting                             | What it controls                                          |
| ----------------------------------- | --------------------------------------------------------- |
| Position                            | Chooses position. Options include: Top, Bottom.           |
| Stick cart summary on scroll        | Turns stick cart summary on scroll on or off.             |
| Show order note                     | Shows or hides order note.                                |
| Show shipping/tax notice            | Shows or hides shipping/tax notice.                       |
| Show additional checkout options    | Shows or hides additional checkout options.               |
| Show checkout button                | Shows or hides checkout button.                           |
| Terms and conditions link           | Sets the destination link for terms and conditions link.  |
| Show shipping calculator            | Shows or hides shipping calculator.                       |
| Shipping calculator default country | Sets the content for shipping calculator default country. |
