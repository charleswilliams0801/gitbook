# popup

The Pop-up displays promotional or informational content based on trigger and visibility settings. It can contain text, images, buttons, email signup, social links, a countdown, or a discount code.

## Where to find it

Open **Customize → Overlay → Pop-up**.

## Section settings

### Style

| Setting                       | What it controls                                |
| ----------------------------- | ----------------------------------------------- |
| Color scheme                  | Chooses the color scheme used for color scheme. |
| Background image tint opacity | Adjusts background image tint opacity.          |

### Trigger

| Setting         | What it controls                                                                     |
| --------------- | ------------------------------------------------------------------------------------ |
| Show trigger    | Chooses show trigger. Options include: Click, Delay, Exit intent, Copy to clipboard. |
| Trigger element | Sets the content for trigger element.                                                |
| Delay seconds   | Adjusts delay seconds.                                                               |

### Visibility

| Setting                  | What it controls                    |
| ------------------------ | ----------------------------------- |
| Show to guest users only | Shows or hides to guest users only. |
| Show on mobile           | Shows or hides on mobile.           |
| Days to remain dismissed | Adjusts days to remain dismissed.   |

### Layout

| Setting                        | What it controls                                                      |
| ------------------------------ | --------------------------------------------------------------------- |
| Position                       | Chooses position. Options include: Center, Bottom left, Bottom right. |
| Text alignment                 | Chooses text alignment. Options include: Left, Center, Right.         |
| Padding                        | Chooses padding. Options include: Small, Medium, Large.               |
| Shrink width to pop-up content | Turns shrink width to pop-up content on or off.                       |

### Background image (optional)

| Setting | What it controls                  |
| ------- | --------------------------------- |
| Image   | Selects the image used for image. |
